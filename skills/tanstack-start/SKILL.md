# TanStack Start quality

## Routes

- File routes in `src/routes`; `routeTree.gen.ts` is generated by the Start plugin — never edit it by hand.
- Validate search params and path params with Zod in the route definition.
- Loaders fetch through TanStack Query (`ensureQueryData`) so SSR and client navigation share the cache.

## Server functions

- `createServerFn` for every server-side operation; validate input with `.validator(zodSchema)`.
- Server functions are network endpoints: authenticate and authorize inside each one (or in shared middleware), never trust the caller.
- Keep secrets and DB access in server functions or server-only modules; they must never reach the client bundle.

## SSR and hydration

- Render the same tree on server and client; read browser-only APIs in effects.
- Stream slow data with deferred loaders instead of blocking the whole page.

## Errors

- `errorComponent` and `notFoundComponent` per route that loads data.
- Map server function errors to typed results; log the cause server-side with the trace id.

See the react skill for Query, Form, Table and Zod conventions shared with Vite SPAs.
